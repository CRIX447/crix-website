Deployment Check

Verifies every required file is actually live on this domain, and whether your latest push made it here.

Your deployment looks out of date

Making a GitHub repo private commonly breaks Vercel's access, so deploys stop without any obvious error and the live site keeps serving old files.

  1. Open vercel.com/dashboard → your project → Deployments. Is the newest one from your last push, or days old?
  2. Go to Settings → Git. If it says the repository can't be found or access was revoked, click Reconnect.
  3. On GitHub: Settings → Applications → Vercel → Configure, and grant it access to the private repo.
  4. Back on Vercel, hit Redeploy on the latest commit.
